# 效果优先创作的架构约束

## 目的

本约束指导阅读效果优化如何接入现有可信创作内核。它只规定跨任务边界；具体交付和验收由子任务 Spec 定义。

## 不可削弱的内核

字节级证据定位、不可变提交、主线选择、草稿与定稿隔离、POV 信息边界、回改影响面和可重建投影继续拥有最高兼容性优先级。优化不得通过绕过这些机制换取表面生成速度或文学评分。

现有工程测试是回归底线，不是阅读效果证据。

## 权威与派生方向

权威方向保持为：

```text
作者确认材料 / 定稿正文 / 不可变提交
  → 抽取与派生记忆
  → 检索和上下文
  → 草稿候选
  → 作者定稿
```

AI 规划、滚动摘要、检索排序、方法卡和作者偏好均不能反向静默修改权威材料。自动生成的章纲先处于候选状态，作者批准后才能成为作者意图。

动态人物关系、状态和误信仍归 Fact/Belief 账本所有。人物弧和人物卡只保存相对稳定的设计与基线，避免形成第二份动态真相。

## 上下文契约

写作上下文按变化频率和用途组织：

- **稳定材料**：写作协议、核心读者承诺、长期风格与 Canon；
- **卷级材料**：当前卷目标、卷内承诺和有界卷摘要；
- **章级材料**：本章合同、当前 POV 状态、上一章衔接、相关旧场景和近期计划。

这种分层服务于材料准入、审计和潜在缓存。`contextHash` 只证明上下文身份，不代表服务商缓存命中；缓存收益必须由真实 provider 行为验证。

所有材料至少保留来源、版本、用途和可信级别。进入正文生成的定稿旧片段还必须能够判断可见性并回指来源提交与证据。检索分数和相关性必须保留到预算裁剪，不得在准入前被字典序覆盖。

## 正文衔接与 POV

上一章 `endingState` 是计划，不是实际结局。正文衔接状态必须来自上一章定稿正文及其定稿抽取结果。

定稿原文片段只有在可见性能够验证时才可进入 limited POV 上下文；无法验证时退回 POV 安全摘要。前一章合同、作者版全书摘要和读者已知信息不能替代这项检查。

安全失败采用显式降级，不以“可能没泄密”为通过条件。

## 检索与索引水位

生成依赖检索后，检索索引成为有水位要求的派生投影。定稿、回改、重建和写前检查必须保证索引与所选主线一致，不能继续依赖作者记得手动重建。

召回优先使用伏笔证据、人物、故事线、地点等结构化关系，再以关键词检索补充。语义向量只有在纵向评测证明现有召回不足时才增加。

检索材料属于证据层，默认可以记录原因后省略；安全必需的当前状态和合同知识不能走同一条省略路径。

## 容量与有界记忆

长期记忆增长通过去重、失效记录排除、当前任务相关性排序、按需召回和有界派生摘要控制。

以下内容始终不可因普通预算裁剪而静默丢失：

- 本章合同显式依赖的知识；
- 当前场景所需人物状态、位置、物品和持续效果；
- 当前行动依赖的信念、误信与相关秘密；
- 本章必须推进或回收的故事承诺。

完成安全分层后仍超过容量时，继续返回明确容量冲突或要求拆分任务。

## 阅读效果审查

可信审查与效果审查是两条不同轨道：

- 可信审查处理事实、POV、时间线、Canon 和合同硬约束，可维持 blocking；
- 效果审查处理期待、张力、情绪、人物声音、信息释放和章末追读，默认 warning。

OpenLoop 只表达伏笔类开放回路，不等同于爽点或情绪兑现。读者承诺和 Payoff 若被引入，必须拥有独立语义与正文证据，不能用固定章节间隔推断文学效果。

## 生成与模型策略

普通章和关键章允许不同生成策略，但所有候选都遵守同一事实与定稿边界。多候选只针对少量高价值段落，不由模型分数替代作者选择。

写作、规划、抽取、可信审查、效果审查和修稿可以拥有独立模型与采样参数。任何参数默认值都只是待验证配置，不把“高温”或“大模型”视为质量保证。

结构化输出按 provider 能力降级。流式请求只有在尚未产生正文 delta 时才可透明重试；开始输出后的失败必须保留 partial 并创建新的恢复运行。

## 效果实验契约

创作策略需要可开关、可记录、可消融。至少区分检索、正文衔接、prompt 渲染和生成策略，避免一次改变多个变量后无法归因。

评测包含：

1. 固定前文上的正文工艺对比；
2. 包含配角回归、伏笔回收和卷级推进的长篇纵向对比。

工程正确性和安全性先作为门禁，之后比较阅读偏好、作者采用、成本和耗时。小样本允许平局，保留 holdout，不用单次胜率自动决定回滚。

## 技术边界

继续采用轻依赖的 Node.js、TypeScript、可读文件、SQLite 和 OpenAI-compatible 适配。新增能力必须证明直接改善正文、作者决策或运行可靠性；不引入仅用于架构展示的微服务、Agent 框架、独立向量平台或图谱系统。
