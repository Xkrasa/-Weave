# 建立正文与长篇效果评测基线

## 任务目标

建立可重复、可消融的创作效果评测，记录未修改管线的 baseline，使后续优化能够区分“工程可运行”“读者更喜欢”和“作者更愿意采用”。

## 交付范围

### 正文工艺集

创建 8–12 个原创中文故事种子，覆盖至少三种目标读者与情绪承诺。每个种子包含：

- 黄金三章任务；
- 给定固定定稿前文后的关键转折章；
- 明确的合同、Canon、人物和允许使用的作者样本。

种子不得复制参考项目或版权作品。

### 长篇纵向集

创建 2–3 个包含 30–60 章既定前文的合成项目。后续任务至少覆盖：

- 配角或旧物回归；
- 伏笔推进与回收；
- 人物关系变化；
- 卷级矛盾推进或卷末高潮；
- 一个当前 POV 不可知的秘密。

纵向集用于测量证据召回、POV、安全衔接和长期规划，不只用于文学盲评。

### 实验记录

每次运行保存故事种子、管线版本、功能开关、prompt 渲染器、模型与参数、材料清单哈希、原始输出、usage、耗时和失败信息。支持至少以下独立开关：

```text
retrieval: on | off
continuation: safe-prose | summary-only
promptRenderer: json | mission
revisionContext: legacy | enriched
```

同一对比保持模型、预算和故事材料一致。真实模型实验与默认 `npm test` 分离，测试环境不得意外消耗 API 额度。

## 评价方式

主结果是成对盲评偏好和“愿意继续读”，辅以人物吸引力、场景张力、情绪兑现、人物声音、自然度和章末期待。作者试用还记录候选采用率、人工修改时长与每个接受章节成本。

纵向集另外记录应召回证据命中率、错误召回、POV 泄漏、事实错误和故事承诺推进。

LLM 评审可以扩大覆盖，但只能作为辅助信号；至少一部分样本进行打乱顺序的人工成对盲评。保留原始输出和评审依据。

## 决策规则

小样本允许平局；重要实验至少重复一次以降低单次采样偶然性。保留未参与调参的 holdout。质量持平但成本显著下降可以接受，质量提升但成本大幅增加需要显式取舍，不采用“单次胜率不升就自动回滚”。

## 验收

- 假模型下可完整运行评测清单并生成机器可读报告，默认测试零真实网络请求。
- baseline 报告能重现实验条件并定位每次原始输出。
- 正文工艺集与长篇纵向集分别出报告，不能用一个平均分互相掩盖。
- 至少完成一次当前管线的真实模型 baseline，否则本任务不得关闭。
- 开关能够单独改变目标策略，运行记录能证明实际生效。

## 非目标

- 不建立通用文学总分或模型排行榜。
- 不用少量 LLM 自评分宣称阅读效果提升。
- 不在本任务内实现具体检索、prompt 或生成优化。
