# 将拆书升级为场景分析与方法卡

## 任务目标

把当前以标点和词面统计为主的拆书报告，升级为能够解释场景因果、信息释放、期待兑现和跨章结构的分析，并将可复用部分沉淀为作者确认的原创方法卡。

## 场景分析

在保留章节切分、篇幅和基础统计的同时，使用结构化模型分析：

- 场景目标、阻力、选择、转折和状态变化；
- 读者与角色分别何时获得信息；
- 期待如何建立、延迟、推进和兑现；
- 开头进入场景的方式与章末留下的问题；
- 铺垫、推进和回收跨越哪些章节；
- 详略、对白、动作和心理在场景中的功能。

分析结论必须引用有限原文证据；证据用于定位，不表示可以把参考原文直接注入创作 prompt。

## 方法卡候选

从多章重复出现的结构中提炼抽象方法候选，沿用现有 `signal / diagnosis / process / output / positive / negative / selfCheck` 容器。

正反例必须重新创作，不复制参考作品表达。方法候选初始为 `generated/draft`，作者确认后才能进入正式方法库；确认记录来源分析和内容哈希，但不把参考作品事实写入 Canon。

## 版权与出处边界

拆书产物继续保持 reference 身份，限制长引用，区分“结构观察”和“可复用表达”。方法卡只保存抽象策略和原创示例，不保存大段原文或进行近义替换式仿写。

## 验收

- 报告能够解释至少一个场景的选择与转折，而非只根据“因为/所以”打标签。
- 能区分读者知道与角色知道的信息释放时点。
- 方法候选可由作者查看、编辑、批准或拒绝，未批准不会自动热加载。
- 方法卡正反例为原创，来源作品长原文不会进入正文上下文。
- 模型失败不会把空分析当成成功；结构化输出经过本地校验。
- 方法卡接入后可通过 benchmark 比较收益，无效卡可以禁用和回滚。

## 非目标

- 不建立参考作品原文语料库用于直接仿写。
- 不用固定重叠字数阈值替代人工版权判断。
