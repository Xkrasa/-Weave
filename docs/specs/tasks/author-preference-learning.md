# 从作者修订沉淀创作偏好

## 任务目标

让系统从作者实际选择、拒绝和手工修改中学习“这位作者在这本书里怎样写”，减少重复提出相同建议，同时不把偏好学习变成新的事实污染源。

## 学习信号

记录本地创作行为：

- 候选被采用、拒绝或修改后采用；
- finding 被修复、忽略或豁免及理由；
- AI 草稿到作者定稿之间的段落差异；
- 作者显式标记的优秀段落和不喜欢的表达。

信号按书籍、人物、场景类型和任务阶段分类。单次选择只形成弱证据，不直接生成永久规则。

## 偏好候选与批准

系统可以归纳风格倾向、人物声音、常见修改原因和方法适用性，但先形成可解释的偏好候选。作者可以查看来源、编辑、批准、禁用和删除。

偏好可能作用于后续样本选择、方法路由和效果审查降噪；不得自动修改 Canon、事实、人物当前状态或已批准卷弧。

## 场景化风格

句长、对白、心理和描写密度只按场景类型观察，不为打斗、日常、推理和感情场景应用同一机械阈值。人物声音卡保存稳定表达特征，动态知识与关系仍读取账本。

## 隐私与可逆性

学习数据保存在项目本地，提供关闭学习和清除偏好的能力。任何偏好都能回指来源行为并撤销，撤销后不再影响新运行，历史运行记录保持不变。

## 验收

- 采用、拒绝和手工修改能形成可区分的本地学习信号。
- 弱信号不会自动变成作者规则；偏好候选必须可查看和批准。
- 已批准偏好能影响样本或方法选择，运行记录能说明实际作用。
- 禁用或删除偏好后的新 prompt 不再包含其内容。
- 偏好学习不会改变 Fact/Belief/Canon 或绕过 POV。
- 同一句长和对白指标不会无差别用于所有场景类型。

## 非目标

- 不训练或微调基础模型作为本任务前提。
- 不把作者对一次候选的偏好泛化成永久文学法则。
