# 建立有界卷级与 POV 记忆

## 任务目标

让长篇项目在第 150 章以后仍能获得“全书走到哪、本卷要做什么、当前人物为什么这样行动”的有界上下文，同时避免 `pov:knowledge` 随章节无限增长并非必要地撑爆预算。

## 派生摘要

定稿后维护绑定主线水位的卷摘要和 story-so-far 摘要。摘要来自定稿抽取和已批准卷弧，不来自草稿或未来合同事实。

摘要分为：

- **作者版**：服务规划和作者查询，可以包含作者已确认的秘密；
- **POV 安全版**：服务 limited POV 正文，只包含当前视角可见的信息；
- **卷级版**：突出本卷矛盾、承诺、人物选择和未解决压力。

摘要是有损派生定位材料，不能回答需要精确证据的问题，也不能替代 Fact/Belief/OpenLoop。必要时通过检索回读定稿原文。

摘要更新失败不回滚合法提交，但必须标记派生状态并阻断依赖它的生成，不能静默沿用旧摘要。

## POV 知识分层

按以下优先级处理：

1. 本章合同显式知识和当前场景状态；
2. 当前行动依赖的信念、误信、秘密与持续效果；
3. 本章相关伏笔、人物和地点状态；
4. 当前卷相关背景；
5. 久远且无关的历史记录。

前两类不得被普通预算裁剪。第三至五类可以去重、排除失效项、压缩或改为按需检索，但所有省略必须可审计。

压缩后仍无法保证安全必需材料容量时，继续返回 `split-required` 或 `capacity-conflict`，不得把安全材料简单改成 optional。

## 更新与重建

优先使用确定性聚合维护有界摘要；需要模型压缩时，压缩结果仍保存输入水位、来源范围和内容哈希。回改旧章后，从失效点重放相关摘要，不保留混合新旧主线的内容。

## 验收

- 合成长篇项目的 POV 材料规模受预算控制，不随全部历史线性无界增长。
- 本章显式知识、当前场景状态和关键误信在裁剪后仍完整存在。
- 作者版摘要中的秘密不会经 POV 版摘要泄漏。
- 回改后摘要、材料哈希和主线水位同步失效并重建。
- 摘要中的关键状态可以回指账本或定稿证据。
- 真正超过安全容量时仍明确失败，不发生静默降级。

## 非目标

- 不追求“彻底消除容量冲突”。
- 不用一份全书摘要替代结构化记忆和原文检索。
