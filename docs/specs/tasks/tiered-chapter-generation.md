# 实现普通章与关键章分级生成

## 任务目标

把额外模型调用集中用于最影响阅读效果的章节和段落，改善开头、关键选择、高潮与章末，同时控制普通连载章节的成本和延迟。

## 普通章路径

保留当前一次流式起草、人工编辑和定稿门禁。检索、安全衔接与 prompt 渲染按已验证配置生效，不强制每章增加自修、多候选或多角色讨论。

## 关键章路径

作者可以在卷弧或章合同中标记卷首、卷末、大高潮、重要关系转折等关键章。关键章可启用：

```text
场景规划
  → 整章起草
  → 效果与可信问题定位
  → 仅对高价值段落生成 2–3 个候选
  → 作者比较与选择
  → 合并、独立复检、人工定稿
```

候选主要面向开头、核心选择、高潮释放和章末，不默认生成三份完整章节。场景规划是生成辅助材料，不直接成为事实或作者计划。

## 候选治理

每个候选记录父草稿、目标段落、生成目标、模型、prompt 版本、usage 和选择状态。作者选择前不得覆盖草稿；选择后继续复用局部合并与草稿哈希失效流程。

LLM 评分只能帮助定位候选差异，不能自动替作者决定文学优劣，也不能自动定稿。效果审查 warning 不自动触发无限重写循环；重写次数和预算有明确上限。

## 验收

- 普通章保持现有单遍路径和调用预算，不被强制增加候选。
- 关键章能够只对指定高价值段落生成多个候选，其他段落不变。
- 候选可比较、可选择、可追溯，未选择候选不污染草稿和账本。
- 合并后仍要求重新抽取、审计和独立复检，定稿边界不变。
- 达到候选或预算上限后停止，不产生自动修稿死循环。
- A/B 报告比较作者采用率、阅读偏好和每个接受章节成本，而非只比较生成次数。

## 非目标

- 不引入多 Agent 角色扮演框架或无人值守整书生成。
- 不用 LLM 总分替代作者选择。
