## 〇、总纲：「只要爽就行」对生产系统的含义

- 生产目标不是文学性，而是**爽点密度 × 钩子留人 × 承诺兑现**的稳定输出，核心指标是完读率/追读率（免费）与订阅留存（付费）。
- 这类文本**模板化程度高、结构可复用**，是「拆书 → 方法卡 → 模板化生成」管线收益最大的场景；文笔只需及格线（彼篇 [S2] FAQ：节奏 > 文笔）。
- 流派 = 预制结构包：每个流派自带「金手指菜单 + 开局模板 + 爽点节奏 + 雷点黑名单」。选择流派后，上述四件套决定了 80% 的章节结构，剩下 20% 是差异化。

## 一、男频·末日流打法

### 1.1 细分流派与金手指菜单

| 细分流派 | 代表作 | 常见金手指 | 核心爽点机制 |
| --- | --- | --- | --- |
| 囤货空间流（末世前） | 《末世重生：无限系统空间囤物资》类 | 储物/田园/灵泉/修炼空间；重生先知 | 信息差囤货的安全感 + 别人没抢到的优越感 |
| 避难所升级流 | 《全球废土：避难所无限升级》 | 末日生存系统 + 可无限升级的基地 | 经营建设 + 装备代差碾压（「咱们还在点油灯，人家冰箱都用上了」） |
| 废土重建流 | 《第一序列》《狩魔手记》 | 系统流元素 + 精神意志设定 | 秩序重建、一步步变强 |
| 末世无限流 | 《末日乐园》（女频无 CP） | 副本闯关能力 | 强反转、副本解谜 |
| 传统丧尸/进化流 | 《末日蟑螂》《末世凡人》 | 异能进化 | 杀伐果断 + 搜刮收获 |

- 空间金手指细分（C 级盘点）：田园空间（种田自给）、灵泉空间（治愈强化）、储物空间（无限囤货）、修炼空间（升级加速）、机械/医疗空间（特殊功能）——**单一功能挖深 > 万能外挂**（与彼篇「金手指独占性」互证）。
- 爆款标签堆叠公式（C 级）：【末世】+【重生】+【囤物资】+【杀伐果断】+【不圣母】+【无限空间】+【异能】+【黑科技房车】；女频末日版加「狠人大女主」「无 CP」。
- 新变体：「恶人全员重生流」（反派也重生，博弈张力）；「反圣母流」本身已成新流量密码。

### 1.2 开局模板（前三章具体安排）

**模板 A：重生囤货型**——第 1 章重生回到末日前 N 天 + 疯狂囤货清单（购物爽点即小爽点）；第 2 章末世爆发前兆 + 旁人不信（信息差优越感）；第 3 章灾难降临 + 主角从容应对 vs 他人惨状。

**模板 B：全民游戏型（实拆样本）**——《全球废土》第一章的 10 个结构要点：

1. 第一行即系统公告开场（【欢迎来到末日生存游戏】），零环境铺垫；
2. 8 条规则手册直接投喂世界观（借规则怪谈手法），规则本身埋钩子（「战胜变异生物有惊喜」）；
3. 主角第 3 段才登场，**全章无外貌描写**，一句动作+一句心理立「冷静理性」人设；
4. 灾变背景只用约 60 字倒叙交代完（耀斑+小行星+晕过去）；
5. 世界频道/区域频道的聊天记录承担「反应流」功能：他人慌乱衬托主角冷静，顺带完成信息交换（有人被狮子盯上、地下安全屋是坟墓、无人有水源）；
6. 强行限制玩家抱团（每日 1 条世界频道发言）——用规则解释为什么没有「国家机器立刻救场」，堵住逻辑漏洞；
7. 全章核心是一个**决策点**：地上木屋（发展潜力）vs 地下坑洞（稳妥安全），完整展示主角的权衡过程——理性人设靠「选择」立住，不靠形容词；
8. 倒计时装置从第一章就上弦：【距离下次灾难事件爆发倒计时：5天】+ 灾难预告（酸雨）；
9. 章末最后一行才亮出真正的金手指：「是否绑定末日生存系统？」——把最大悬念压在章末钩子上；
10. 文体：1–3 句一段，系统文字用【】包裹，对话/频道消息占比高，零说明书式旁白。

**模板 C：天灾倒计时型**——开篇天象异变 + 预言/重生者示警 + 全城嘲讽（压抑）→ 第一波天灾打脸。

前 15 章目录的节奏样本（起点官方）：末日生存游戏 → 升级的希望 → 饮水危机！初次升级 → 第一日结束 → 捡漏！直面威胁 → 第一次战斗，大爆！→ 幽能！展望未来 →……即「危机 → 升级兑现 → 收获清点」的日循环，**灾难周期 = 天然的卷结构**。

### 1.3 节奏模型

- **灾难周期驱动**：预告（7 天倒计时）→ 备灾（囤货/建设小爽点密集）→ 灾难爆发（压抑+战斗）→ 渡过+结算（大爽点：收获清点、面板跳数字）→ 新预告。周期即卷。
- 安全感经济：囤货/物资清点本身是爽点（安全感账户充值）；饥荒、抢掠、人性黑暗是取款（压抑）。C 级共识：**压抑不过夜**（与彼篇互证）。
- 双线结构：经营建设线（种田爽）+ 探索战斗线（冒险爽）交替，避免单一循环疲劳。
- 长线风险（NGA 读者观点，C 级）：「末世文不适合写长，长了易烂尾」——规划时按 3–5 个灾难周期设计完本节奏。

### 1.4 雷点黑名单（男频末日）

- 圣母/圣父：无原则救助外人连累队友，或道德说教读者；
- 降智送人头：为推剧情让配角愚蠢牺牲；
- 出彩女配怕威胁女主地位被「故意写死」；
- 感情线：无 CP 或单女主是安全区；暧昧拉扯过长、后宫化管理是重灾区；
- 囤货/种田细节过长不推主线（水字数）；
- 智斗文对笔力要求高，快产场景不建议首选（C 级教程共识：套路清晰的题材更容易写好）。

### 1.5 女性角色惯例

单女主或无 CP 为主流安全选项；女性角色要么是并肩战斗的伙伴、要么是基地建设的功能角色；「只敢跟主角闹、对外就怂」的小仙女人设被读者明确反感（书院讨论，C 级）。

## 二、男频·恐怖流打法

### 2.1 「恐怖但爽」三定律（人民网/中国作家网评论 + 社区分析）

1. **给读者安全感框架**：系统、经营、副本规则等确定性结构包裹恐怖内容（《冒险屋》的手机任务、《惊悚乐园》的游戏框架）——恐怖是外壳，养成/智斗是骨架；
2. **幽默调节**：吐槽、玩梗、宅元素中和压迫感（《惊悚乐园》被评「整体严肃、细节轻松」；主角封不觉「失去恐惧感」的设定让读者感受恐怖、主角消解恐怖，产生反差爽）；
3. **恐怖转正反馈**：恐怖情绪最终转化为「解除威胁/升级收鬼/破解谜题」的收益——吓人的东西是可以变现的资源。

### 2.2 细分流派表

| 细分流派 | 代表作 | 写法重点 | 爽点来源 |
| --- | --- | --- | --- |
| 灵异探险 | 《鬼吹灯》《盗墓笔记》 | 民俗知识 + 探险装备 + 章回式「最险处戛然而止」 | 猎奇、破解机关 |
| 惊悚无限流 | 《惊悚乐园》 | 副本解谜 + 智斗 + 吐槽消解 | 通关智斗、戏仿玩梗 |
| 经营恐怖 | 《我有一座冒险屋》 | 鬼屋经营 + 任务升级 + 解决鬼魂执念 | 收服鬼怪、游客尖叫（反应流） |
| 规则怪谈 | 各规则类网文 | 规则设计 + 违和感 + 解谜 | 识破规则、反杀「它」 |
| 民俗疯癫 | 《道诡异仙》 | 不可靠叙事 + 真幻交错 | 认知冲击、哲学共鸣 |

### 2.3 规则怪谈写法五步（B/C 级教程综合：规则怪谈 WIKI、B 站专栏、飞书文档）

1. **场景背景先行**：时间、地点、人物身份必须具体（「没有场景的规则怪谈必然失败」）；
2. **规则设计**：正常条款中混入「它」修改过的条款；强调正常逻辑下不该强调的东西，暗示规则之内不该存在的东西；
3. **埋三类线索**：规则矛盾（互相打架的条款）、认知错位（把安全说成危险）、细节违和（碎片化叙事，让读者自己推理出「这里发生过什么」→ 细思极恐）；
4. **网文化改造**：把单则怪谈扩成大小副本结构（新手副本→进阶副本→终极规则），每副本一个反转结局，出人意料但合理；
5. **兑现纪律**：所有违和感必须在后文回收（与「钩了没兑现就是诈骗」同构）。

### 2.4 实拆《我有一座冒险屋》开篇

- 开场即游客吐槽对话（「这么不吓人的鬼屋我还是第一次见」）——用**差评现场**建立「濒临倒闭」的最低起点；
- 背景一段交代：父母失踪 + 辞职接手鬼屋 + 撑不过淡季（压抑三连）；
- 金手指：整理遗物时发现黑色手机——**父母失踪之谜 = 天然长线悬念**，任务系统 = 短线爽点引擎，双悬念嵌套；
- 前 30 章目录可见任务流结构：日常任务 → 噩梦级任务 → 意料之外的奖励 → 25 分 14 秒 → …… → 直播 → 人气增加——**难度阶梯 + 业绩增长**两条曲线，且第 18 章就引入「直播」元素放大反应流（游客/观众的尖叫与吐槽）；
- 人民网评价其「立意新颖」；中国作家网称「来自中国的百鬼夜行」；知乎定性「披着灵异恐怖外衣的欢乐养成文」；
- 已知短板（豆瓣书评）：新场景循环固定为「挑衅→作死→进未开发区域」，长线模式化——生产时可把「场景引入方式」做成轮换池规避。

### 2.5 雷点黑名单（恐怖流）

- 恐怖描写过长不兑现（吓人只是吓人，没有收益转化）；
- 主角太怂（读者代入的是「我敢面对」，不是「我怕」——参考封不觉设定）；
- 鬼没逻辑（恐怖规则不自洽，Bug 被读者抓住即崩）；
- 长线模式化（同一场景结构反复）；
- 过度侵犯感官（恶心向内容劝退，恐怖≠猎奇血腥）。

## 三、女频·大女主打法

### 3.1 定义与硬标准

- 大女主文的定义（中国作家网评论口径）：**无论有无男主，主线必须是事业线**；拒绝「男人征服世界、女人征服男人」，结尾女主须靠自己完成成长。
- 演变：宫斗/宅斗（甄嬛、知否、庶女攻略）→ 重生复仇（千山茶客系）→ 事业型/不恋爱脑/事业批（近年）→ 无 CP 大女主 + 末世/悬疑复合。
- 优秀标杆《我妻薄幸》被视为近年典范（中国作家网评论）：参考真实历史制度（秦良玉生平），女主凭医术游历发展，而非悬浮开挂。

### 3.2 细分流派与爽点菜单

| 细分流派 | 代表作 | 金手指 | 核心兑现物 |
| --- | --- | --- | --- |
| 重生复仇 | 《重生之将门毒后》《嫡嫁千金》 | 前世记忆（先知） | 「被后悔」：渣男贱女的下场 + 前世冤屈逐格昭雪 |
| 宅斗/宅斗+经商 | 《庶女攻略》《宠妾灭妻？侯门主母她改嫁权臣》 | 重生/现代知识 | 「翻身欲」或「安全感」（低位逆袭 vs 高位碾压两条路线） |
| 种田经商/年代搞钱 | 年代重生搞钱文（番茄女频第一赛道，C 级） | 重生 + 空间/技能 | 赚钱清单 + 家业壮大（与男频囤货爽同构） |
| 女帝/争霸 | 《扶摇皇后》《女帝本色》 | 武力/智谋/身世 | 权力成就 + 群臣拜服 |
| 马甲文 | 《嫡女归京，马甲一个比一个惊人！》 | 多重隐藏身份 | 信息差打脸：「我知道他们不知道」的优越感 |
| 大女主+末世/无限流 | 《末日乐园》 | 副本能力 | 强反转 + 无 CP 独立人格 |
| 现代事业/豪门 | 现言大女主 | 专业能力/重生 | 事业登顶 + 打脸看不起她的人 |

- **女频爽点与男频的差异**：男频兑现物是「碾压/优越」；女频兑现物是「**被看见、被爱、被后悔**」——打脸的本质是「当年瞎了眼的人终于看见我的价值」，复仇的本质是「亏欠我的人付出代价」。
- 标配反派套件（豆瓣套路总结，C 级）：渣男 + 白莲花庶妹/小三 + 偏心爹 + 毒后妈——出场即读者情绪存钱罐。

### 3.3 开局模板

**古言重生复仇八段式简介**（《将门毒后》官方简介实拆，段落即前 2 章剧情）：

1. 前世身份与付出（将门嫡女，贞静柔婉，痴恋定王）；
2. 被背叛的顶点（妹妹讥讽「江山定了，你也该退了」+ 赐死）；
3. 惨况清单（女儿惨死、太子被废、满门忠烈无一幸免）；
4. 毒誓/重生节点（三尺白绫立誓 → 重生回十四岁）；
5. 敌人清单（极品亲戚/恶毒堂姐妹/新姨娘/渣男故技重来）；
6. 目标清单（家族要护，大仇要报，江山也要分一杯羹）；
7. 男主登场台词样张（桀骜小侯爷墙头宣示）；
8. 感情线承诺（强强联手，宠文一对一，身心干净——雷点前置排除）。

- 前 80 章免费目录节奏：废后(2)→重生(2)→挑拨→沈老夫人→针锋→暗流→广文堂→辩论→惊艳→本宫回来了→不要忍→……→敢杀吗→赌命。特征：**2–4 字短语章名、事件驱动、每 3–5 章一个小对撞**；「本宫回来了」「不要忍」这类章名本身即情绪宣言。

## 四、跨流派共性：可直接进生成层的规则

1. **开局四件套**：冲突/差评现场 →（重生/穿越/系统任一的）身份差 → 金手指预告（不必完全揭晓，压章末更好）→ 倒计时或 deadline（灾难预告/任务期限/复仇节点）。
2. **章节三问**（每章蓝图必答）：本章爽点是什么（类型+位置）？章末钩子是什么（四型选一）？兑现了哪条读者承诺？
3. **信息投放三载体**：系统面板【】、对话/频道消息、内心吐槽——零说明书旁白。
4. **反应流原则**：主角的强，必须通过他人的震惊/恐慌/后悔呈现（频道聊天、游客尖叫、敌人悔恨），不靠叙述者夸。
5. **兑现物按频道分枚举**：男频 = 碾压/收获/升级/恐惧他人；女频 = 被看见/被爱/被后悔/扬眉吐气。
6. **毒点黑名单合并**（男频 5 条 + 恐怖 5 条 + 女频 5 条，见上文各节）——可做成生成前检查与 review 提示词。
7. **标题/简介即承诺**：标题承诺什么，前三章必须兑现什么。

## 五、生产管线映射（与 Weave 现有规格的对接假设）

「参考想法/参考文章 → 快速生产」的管线，用现有 spec 词汇表达：

```text
参考文章/想法输入
  → 拆书（scene-deconstruction-methods）：识别流派模板、爽点节奏、钩子类型
      ↳ 产出方法卡候选（generated/draft，作者确认后启用）
  → 流派路由：从本报告第一/二/三节的「流派-金手指-爽点」表选择结构包
  → StoryPromise（story-planning-model）：目标读者(频道)、题材、核心幻想、独特卖点、主要情绪体验
      ↳ 兑现物枚举按频道初始化（第四节第 5 条）
  → VolumeArc：灾难周期 / 复仇阶段 / 任务难度阶梯 = 卷结构
      ↳ 每卷一个大爽点（Boss 战/身份曝光/仇人伏法）
  → RollingPlan（10–30 章）：最近 3 章写明「爽点类型+位置、章末钩子型、兑现的承诺」
      ↳ 章节三问作为蓝图必填字段
  → 分级生成（tiered-chapter-generation）：普通章单遍；关键章（卷首/高潮/章末钩子）对高价值段落出 2–3 候选
  → reader-effect review：毒点黑名单检查、爽点密度与类型轮换、承诺-兑现对账
```

- 边界重申：流派打法是**软目标与策略候选**，按 `goal-and-requirements.md` 不得做成统一配额或阻断条件；拆书产物保持 reference 身份，结构观察 ≠ 表达复制。
- 与既有调研的关系：爽点密度/钩子四型等节奏结论见 `webnovel-shuangwen-vs-quality-craft.md`；作者级一手经验（猫腻节奏公式、乌贼世界观优先）见 `bestseller-webnovel-craft.md`——本文的流派包是其「类型化落地层」。
