# 网文写作工艺参考

> 本文是三篇外部调研的**归纳本**，后续参考以本文为准；三篇原文保留在同目录，仅作为来源与取证记录。原文来源编号沿用各篇自己的清单，前缀映射：
>
> - 〔bestseller S*〕= `bestseller-webnovel-craft.md`（作者一手访谈为主，A 级）
> - 〔两轨 S*〕= `webnovel-shuangwen-vs-quality-craft.md`（爽文工程化为 C 级，精品侧 A/B 级但多为摘要转述）
> - 〔play §*〕= `shuangwen-genre-playbooks.md`（男频有正文实拆，女频仅简介级证据）

## 使用规则

1. 证据等级：**[A]** 一手访谈/平台一手数据；**[B]** 权威评论；**[C]** 经验帖，仅作可检验假设。
2. 所有频率数字（「每 1.8 章一次情绪高峰」「每 500 字一转折」「90% 追更率」）一律**不采信**，不进系统常量（见 §十一）。
3. 节奏、密度、爽点类结论是**可实验的策略候选**，不是配额，不得做成生成阻断条件（`goal-and-requirements.md` 非目标第 3 条）。
4. 任何条目进入系统前，需经作者确认并按 `docs/specs/effect-first/SPEC.md` 的效果实验契约做 A/B。

## 一、核心原则（作者一手自述，[A]）

1. **卖点先于文笔**。猫腻「大红书配方」：70 分以上的文笔 + 整个套路文，关键是节奏。文笔是及格线不是胜负手。〔bestseller S3〕
2. **节奏是循环不是一直快**：小高潮 → 平复期 → 余韵；高潮越小平复越短；几个小高潮后上大高潮，大高潮前先「挖好扣子」；环套环**两三层即可**；几万字的平淡过渡要「硬生生生个事」。〔bestseller S3〕
3. **提前放大爽点 = 抬高兴奋阈值**。《庆余年》宫廷斗诗提前十几章，短期拉数据、后续难写。〔bestseller S3〕
4. **情绪兑现高于「主角赢」**：「『自己赢』不是快感的来源，『看对方怎么输』才是」。对方要「惨到非常后悔、非常痛心」；受压迫很久却在翻身瞬间完结，读者不高兴。〔bestseller S3〕
5. **强刺激强矛盾必须爆发**。「网文不一定是爽文，但一定需要强刺激与强矛盾」；只写水面下的挣扎、矛盾不爆发，读者烦躁。〔bestseller S7〕
6. **代入感是比爽点更底层的约束**：弱化升级快感问题不大，弱化代入感问题很大。〔bestseller S7〕
7. **安全感 + 可控的不安全感**：主角要有安全感才撑得住 300 万字；但要有意制造可控的不安全感（调走保护者、靠山互疑），且作者随时能收回。〔bestseller S3/S4〕
8. **世界观先于升级体系**；「前面写的两三百万字都在约束着结局」——不能加新东西或新外挂解决问题，必须从旧线索里找路。〔bestseller S7〕
9. **钩子是术，兑现是道**：「钩了没兑现，就是诈骗」；每章强钩会疲劳，宜强弱交替；钩子 ≠ 狗血。〔bestseller S11；「作者与读者斗智斗勇」见 S3/S6〕

## 二、结构公式（[C]，作可检验假设）

1. **先压后弹**：被低估的主角 + 独占金手指 → 被压制（蓄压）→ 反转碾压（释放）→ 围观震惊（余韵）。压抑多深，爽就有多强。〔两轨 S1/S14〕
2. **爽点三级**（只取结构，不取频率数字）：小爽点（章级：一句妙语、小反转、小收获）；中爽点（数章级：完整打脸、关系突破、谜题揭晓）；大爽点（卷级高潮：终局逆转、身份曝光、多伏笔同时回收）。〔两轨 S2〕
3. **钩子型合并清单**（两篇互补去重为五类）：悬念式（不可能之人/之声）；反转式（最后一行翻案）；情绪炸弹式（积蓄矛盾章末爆发）；信息投放式（章末重磅信息）；对话断句/动作未完成式（话说一半、事做一半）。〔两轨 S2 + bestseller S11〕
4. **章内三模板**：起承转爽（回顾→冲突→升级→转折→反击+钩子）；过山车（紧张→缓→更紧→假结局→最紧→钩子，关键在「以为结束了」）；信息揭露递进（线索→结论→推翻→更大秘密，每次推翻是小爽点）。〔两轨 S2〕
5. **黄金三章**：第一章开篇即冲突、控人数、内心吐槽切入；第二章立「与众不同」+ 金手指亮相；第三章小冲突 + 打脸 + 悬念收尾。禁平铺背景、说明书式登场。〔两轨 S3；「黄金一章/前 300 字」趋势见 bestseller S12〕
6. **装逼打脸四进阶**：拒绝平等对话、高维碾压（不给对手建立竞争关系的机会）；金手指贵在独占而非无敌（单一功能挖深 > 万能外挂，加限制反而提升真实性〔两轨 S6 B级〕）；读者「玻璃心」阈值变低（核心利益受损的压抑段读者只想跳过）；压抑要短、兑现要快。〔两轨 S1〕

## 三、信息与视角（跨级）

1. **信息投放三载体**：系统面板【】、对话/频道消息、内心吐槽——零说明书式旁白。〔play §四〕
2. **反应流原则**：主角的强必须通过他人的震惊/恐慌/后悔呈现（频道聊天、游客尖叫、敌人悔恨），不靠叙述者夸。〔两轨 + play §四〕
3. **限知叙事与伏笔逐格揭示**：先让读者理不清头绪，再逐格显影；预叙梦境、匿名预示片段维持长篇整体性。〔bestseller S9〕
4. **用行为写心理**：动作、行为、选择表现人物状态，而非直接陈述情绪。〔bestseller S7〕
5. **细节与资料整合**：沉浸感靠细节；读资料时就知道要用在哪，不是写到才临时找。〔bestseller S6/S7〕

## 四、流派包：男频末日（含 A 级正文实拆）

1. **细分与金手指**：囤货空间（信息差安全感）、避难所升级（经营+装备代差）、废土重建、末世无限流、传统丧尸进化。金手指单一功能挖深 > 万能外挂。〔play §1.1〕
2. **开局模板**：
   - A 重生囤货型：重生+囤货清单 → 灾前兆+旁人不信 → 灾至+主角从容对照他人惨状。
   - B 全民游戏型（实拆《全球废土》第一章，10 要点）：第一行系统公告零铺垫；规则手册自带钩子；主角第 3 段登场、全章无外貌、靠决策立人设；60 字倒叙交代灾变；频道聊天承担反应流+信息交换；用规则堵「为什么没人救」的逻辑洞；全章一个核心决策点；倒计时第一章上弦；金手指压到最后一行；1–3 句一段、【】包裹系统文字。〔play §1.2〕
   - C 天灾倒计时型：天象异变+示警+全城嘲讽 → 第一波打脸。
3. **节奏模型**：灾难周期（预告→备灾→爆发→结算→新预告）即天然卷结构；囤货清点是安全感充值、饥荒抢掠是取款，「压抑不过夜」；经营线与探索线双线交替防疲劳。〔play §1.3〕
4. **雷点**：圣母/圣父；降智送人头；出彩女配被写死；暧昧拉扯过长；囤货细节不推主线；智斗文快产慎选。〔play §1.4〕

## 五、流派包：男频恐怖（A/B 级评论 + C 级打法）

1. **恐怖但爽三定律**：给安全感框架（系统/经营/副本规则包裹恐怖）；幽默调节（吐槽消解压迫，反差即爽）；恐怖转正反馈（吓人的东西可变现为收益）。〔play §2.1〕
2. **细分**：灵异探险（民俗+装备+章回断章）、惊悚无限流（副本+吐槽）、经营恐怖（任务升级+收服鬼怪）、规则怪谈、民俗疯癫（不可靠叙事）。〔play §2.2〕
3. **规则怪谈五步**：场景背景先行；正常条款混入被改条款；埋三类线索（规则矛盾/认知错位/细节违和）；扩成大小副本结构；**所有违和感必须后文回收**。〔play §2.3〕
4. **实拆《冒险屋》**：差评现场建立最低起点；压抑三连一段交代；金手指=父母失踪之谜（长线）+任务系统（短线）双悬念嵌套；难度阶梯+业绩增长两曲线；反应流靠游客/观众。短板：场景引入模式化，可用轮换池规避。〔play §2.4〕
5. **雷点**：恐怖不兑现；主角太怂；鬼没逻辑；长线模式化；过度猎奇血腥。〔play §2.5〕

## 六、流派包：女频大女主（**证据较弱**：正文未取到，基于官方简介+目录+评论三角验证）

1. **硬标准**：无论有无男主，主线必须是事业线；结尾女主靠自己完成成长。〔play §3.1〕
2. **兑现物差异（最重要的一条）**：男频兑现 = 碾压/收获/升级/恐惧他人；女频兑现 = **被看见、被爱、被后悔、扬眉吐气**——打脸的本质是「当年瞎了眼的人终于看见我的价值」。〔play §3.2〕
3. **重生复仇八段式简介**（实拆《将门毒后》）：前世付出 → 被背叛顶点 → 惨况清单 → 毒誓/重生节点 → 敌人清单 → 目标清单 → 男主登场 → 感情线承诺（雷点前置排除）。章名 2–4 字、事件驱动、每 3–5 章一个小对撞。〔play §3.3〕
4. **毒律**：忌连续多章铺垫悲惨（第 1 章内必须见反击或预告）；恋爱脑回潮；雌竞过度；男主人设压过女主；反派也要有逻辑（零降智是卖点）。〔play §3.6〕

## 七、跨流派共性（可检验的规则候选）

1. **开局四件套**：冲突/差评现场 →（重生/穿越/系统任一的）身份差 → 金手指预告（压章末更好）→ 倒计时或 deadline。〔play §四〕
2. **章节三问**：本章爽点是什么（类型+位置）？章末钩子是哪型？兑现了哪条读者承诺？〔play §四〕
3. **兑现物按频道枚举**（见 §六.2）。
4. **毒点黑名单合并**：男频 5 + 恐怖 5 + 女频 5，见各节。
5. **标题/简介即承诺**：标题承诺什么，前三章必须兑现什么。〔play §四〕

## 八、平台机制差异

- **番茄**（免费+时长分成）：追求完读率/追读率；标题即爽点；短句短段适配手机；每章必有情绪释放点；数据导向调剧情。〔两轨 S7 + bestseller S1/S2〕
- **飞卢**（付费快节奏）：单章约 2000 字、每章打脸/收获；「震惊流（反应流）」；签到流等强模板。〔两轨〕
- **起点**（订阅）：爽点密度可略低，要求卷级架构与长期留存。〔两轨 + bestseller〕
- **含义**：节奏密度没有单一正确值，适合作者的**平台/题材偏好维度**，不是全局参数。〔两轨 §四〕

## 九、文笔与「有趣」（[A] 为主）

1. 文笔三合成：节奏感（句段服务情绪峰值与信息释放）+ 细节与语感的具体性 + 用行为写心理。〔bestseller §8〕
2. **有趣日常是稀缺资源**：日常有趣到读者催更日常而不骂水字数；幽默多源于反差与错位；类型融合产生新鲜感。〔bestseller S8/S9〕
3. 猫腻准则：「尊重读者、讨好自己」——不为深度给读者添堵，也不跟风写。〔bestseller S5〕

## 十、反例与边界

阈值抬高（爽点提前透支张力）；减法失败（弱化代入感）；坑作（未收束支线，《盗墓笔记》）；配角越鲜活越不能随意处置（《大奉打更人》后期负面案例）；锐利感 vs 缜密（不回头改 vs 过细致啰嗦，修与不修都有代价）；文笔炫技（脱离叙事功能的辞藻是毒点，但属经验判断不宜硬规则）；AI 灌水被平台整治。〔bestseller §四；两轨 S13〕

## 十一、明确不采信清单

- 「每 1.8 章一次情绪高峰」「bottom10% 4.7 章」「连续 3 章平路追读掉」——厂商自称，无原始数据。〔两轨 S2〕
- 「90% 追更率」「每 500 字一转折」——无来源。〔bestseller S11/S12〕
- 「前 5 章每章 1 个小爽点、每 5 章 1 个大爽点」——未验证假设。〔play §3.3〕
- 行业市场规模数据（502 亿、3269 万作者、IP 3676 亿等）——与写作决策无关，仅在原文档留存。〔bestseller S1/S2〕
- 各「番茄 TOP10 评分」「角色数量适配容量（14/20/24+ 人）」——厂商数据未验证。〔play §3.5〕
